# CineGo

[English](README.md) | [Tiếng Việt](README.vi.md)

Nền tảng đặt vé xem phim. Frontend dùng HTML/CSS/JS thuần, backend dùng Node.js và MySQL.

## Trạng thái

Đang ở giai đoạn đặc tả. Xem `docs/progress.md`.

## Cấu trúc

| Thư mục | Vai trò |
|---|---|
| `frontend/` | Giao diện người dùng |
| `backend/` | API và logic nghiệp vụ |
| `database/` | Migration và dữ liệu mẫu MySQL |
| `docs/` | Đặc tả, schema, hợp đồng API, nhật ký quyết định (viết bằng tiếng Anh) |
| `.agents/` | Quy tắc và workflow cho agent lập trình (Antigravity) |

## Chạy dự án

Chưa có. Mục này sẽ được bổ sung khi backend được dựng.

## Đóng góp

Đọc `AGENTS.md` và `docs/progress.md` trước. Giữ `README.md` và `README.vi.md` đồng bộ với nhau.
