# CineGo

[English](README.en.md) | [Tiếng Việt](README.vi.md)

A movie ticket booking platform. Vanilla HTML/CSS/JS frontend, Node.js and MySQL backend.

## Status

Specification phase. See `docs/progress.md`.

## Structure

| Folder | Purpose |
|---|---|
| `frontend/` | User interface |
| `backend/` | API and business logic |
| `database/` | MySQL migrations and seed data |
| `docs/` | Specification, schema, API contract, decision log |
| `.agents/` | Rules and workflows for coding agents (Antigravity) |
